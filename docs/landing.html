What it does

Left-click
New terminal running claude in your home folder. Instant.
Right-click
Open any folder, recent projects, resume a session, or settings.
Spawn many
Set 1–8 terminals per click — grouped into one Claudey space.
Make it yours
Swap the menubar icon for any image, animated GIFs included.
One window. Every terminal.
Open 2+ and Claudey gives you a single glass space — your claude sessions tiled in a clean, resizable grid. No window juggling.

More

Resume sessions
Right-click lists recent Claude sessions — folder + first prompt. Click to reopen with --resume in place.
Glass terminal space
Multi-terminal panes in one frosted, gray, minimalist window. Resize and they re-flow.
Icon presets
Pick a built-in Claude icon or drop in your own — auto-cropped to fit the menubar perfectly.
Caveman, auto
Optionally installs the Caveman plugin on first launch, so a fresh machine is ready with zero setup.

Install

Open the .dmg, drag Claudey to Applications.
Right-click → Open once, to clear Gatekeeper. Or: xattr -dr com.apple.quarantine /Applications/Claudey.app
